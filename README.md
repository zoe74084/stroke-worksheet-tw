# 台灣標準國字筆順字帖

輸入國字後，可自訂筆順提示、注音、部首、筆畫數與練習格，產生可列印的國字練習字帖。

## 功能

- 以教育部《國字標準字體筆順學習網》的逐筆資料產生黑色筆畫外框。
- 以官方運筆軌跡產生藍色虛線、箭頭與紅色筆順數字。
- 注音、部首、筆畫數可分別開關。
- 勾選的資訊會同時出現在範例列，並在練習列留下空白填寫框。
- 多音字可選擇讀音，也可手動輸入姓名或特殊讀音。
- 注音採教育部教材式直排：聲符由上而下；二、三、四聲放在最後一個聲符右上角，向上回返約半個符號空間；輕聲點放在整組聲符上方。
- 注音符號使用 ButTaiwan `bpmfvs` 專案的 `GenyoMinBopomofo-Regular.ttf`，網站與列印共用同一個內嵌字型。

## 使用

這是純網頁工具，不需要 Python、`server.py` 或資料庫。
放到 GitHub Pages 後，使用者只要開啟網址即可使用。

本機測試可直接開啟 `index.html`，或用任何靜態網站服務開啟。產生字帖時需要連線至教育部筆順學習網及萌典。

## 專案內容

- `index.html`：字帖操作介面與列印版面。
- `fonts/`：注音字型及其原始授權文件。
- `THIRD_PARTY_NOTICES.md`：資料來源與第三方授權摘要。
- `.nojekyll`：讓 GitHub Pages 直接发布資料夾內容。

## 已驗證

2026-08-20 已實際啟動並用瀏覽器檢查：

- `陳` 11 筆、`偽` 11 筆、`倣` 10 筆、`之` 4 筆、`為` 9 筆。
- `陳`、`為`會顯示多音字選單，自訂注音可覆蓋選擇結果。
- 注音、部首、筆畫數可全部關閉，也可單獨開啟。
- 範例列顯示資料；每一個練習列都有對應的空白資訊框。
- 列印模式使用獨立實線邊框與安全內距，避免頁首、頁尾及最左側格線被裁掉。
- 多字列印會以每個字的完整練習欄為分頁單位；頁尾放不下時，整欄移至下一頁。

## 發布到 GitHub Pages

1. 在 GitHub 建立新 repository。
2. 將本資料夾內容上傳到 repository 根目錄。
3. 進入 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. 選擇 `main` 與 `/(root)` 後儲存。

完成後，GitHub 會提供可直接分享給老師與家長的網址。
