# 台灣標準國字筆順字帖

輸入國字後，可自訂筆順提示、注音、部首、筆畫數與練習格，產生可列印的國字練習字帖。

## 立即使用

[開啟台灣標準國字筆順字帖](https://zoe74084.github.io/stroke-worksheet-tw/)

## 功能

- 以教育部《國字標準字體筆順學習網》的逐筆資料產生黑色筆畫外框。
- 以官方運筆軌跡產生藍色虛線、箭頭與紅色筆順數字。
- 注音、部首、筆畫數可分別開關；教育部與萌典筆畫數不同時，可由使用者選擇顯示值。
- 勾選的資訊會同時出現在範例列，並在練習列留下空白填寫框。
- 多音字可選擇讀音，也可手動輸入姓名或特殊讀音。
- 注音採教材式直排，聲調位置適合列印練習。

## 使用方式

1. 輸入要練習的國字。
2. 選擇範例與練習列數，勾選需要的筆順數字、方向線、注音、部首或筆畫數。
3. 多音字請確認讀音；姓名或特殊讀音可自行輸入。
4. 產生字帖後，使用瀏覽器列印功能輸出。
